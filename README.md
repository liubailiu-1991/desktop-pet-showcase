# Desktop Pet Showcase

Desktop Pet Alpha 的公开效果展示页，包含：

- Milo 桌面角色的真实项目动画帧；
- 待机、散步、工作、阅读、思考、完成与休息状态切换；
- 点击和拖动互动；
- 面向普通用户的未来产品能力说明。

## 本地预览

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 说明

这是 Alpha 产品效果展示，不表示所有未来能力都已经开放，也不是已签名或已公证的正式 macOS 发布版本。
